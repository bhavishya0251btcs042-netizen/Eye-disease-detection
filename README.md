# VisionGuard AI - Eye Disease Prediction

This is a web application for detecting eye diseases from retinal scans using Deep Learning.

## How to Run
Simply double-click on the **`start_app.bat`** file in this directory.

It will:
1. Install necessary Python dependencies.
2. Start the local web server.
3. Automatically open the application in your default web browser.

## Requirements
- Python must be installed and added to your system PATH.
- Internet connection (for the first run to download dependencies).

## Usage
1. Drag and drop a retinal scan image onto the upload area.
2. Click "Analyze Image".
3. View the diagnosis result and confidence score.
